# 표준 대상의 고정 기준분포

전국 모든 부동산의 평가가 끝나기를 기다리지 않고 일부 표준 평가대상지에서 기준을 정한다. 새 평가지 추가 시에는 기준을 유지한다. 표준 대상의 구성·표본 가중치·좌표·원자료가 바뀌면 기준 갱신 필요 상태를 표시하고, 변경을 모아 새 기준을 확정한 뒤 기존 평가지 전체에 새 기준을 적용한다. 같은 조건·항목의 원자료는 재사용하므로 길찾기나 시설 조회를 다시 실행하지 않고 점수를 재계산한다.

이전에 확정한 기준 버전은 보존한다. 현재 점수 화면은 항상 적용 중인 기준을 읽어 모든 대상에 적용한다. 동일한 원자료와 같은 기준 버전이면 동일한 점수를 계산한다. 원자료 자체가 바뀐 대상의 점수는 그 새 원자료에 따라 달라질 수 있다.

## 기준 확정

1. 전국 비교에 사용할 표준 대상을 지역, 도시/농촌, 주택 유형, 입지 수준이 치우치지 않도록 선정한다. 자동으로 임의의 지역 표본을 전국 대표라고 간주하지 않는다.
2. 각 세부 항목에 대분류·중분류, 원자료 단위, 점수 방향을 지정한다. 기존에 정한 순서형 지표의 순위와 동점 규칙은 원자료에 적용한다.
3. 자동차 출발 기본값은 다음 11월 첫째 월요일 08:00 한국시간이며, 2026년 10월 준비 시 2026-11-02 08:00이다. 제공자, 경로 기준, 시설 후보군, 검색 반경 등도 동일하게 고정하고 조회 조건에 기록한다. 길찾기 화면에 이 설정을 자동 적용하는 연결은 아직 없다.
4. 선택한 표준 대상 모두의 모든 항목을 확인한 후 평균·표준편차와 표본을 미리 보고 확정한다. 누락·조회 실패·좌표 변경 전 원자료를 0으로 대체하거나 일부 표본만 조용히 사용하지 않는다.
5. 기준 버전에는 알고리즘 버전, 확정 시각, 조회 조건, 항목 정의, 표준 대상의 주소·좌표·표본 가중치·원자료, 항목별 평균·표준편차를 함께 저장한다. 기준을 갱신할 때 새 UUID를 만들고 이전 버전도 유지한다.

## 정규화

항목별 표준 대상 원자료의 평균을 μ, 표준편차를 σ라고 하면 `z = (x - μ) / σ`를 계산한다. 큰 값이 우수한 항목은 `Φ(z)`, 작은 값이 우수한 항목은 `Φ(-z)`를 0~1 점수로 쓴다. Φ는 표준정규분포 누적분포함수다. 확률밀도함수의 높이를 점수로 사용하지 않는다.

기본 표본 가중치는 1이다. 가중치를 사용하는 경우 `W = Σw`, `Q = Σw²`, `μ = Σwx/W`, `σ² = Σw(x-μ)²/(W-Q/W)`로 계산한다. 가중치가 모두 1이면 표본 분산의 분모는 n-1이다. 유효 표본수는 `W²/Q`이다. 이 가중치는 표본 선정 비율을 보정하기 위한 것이며 평가 항목의 중요도와 다르다. 실제 모집단 비율·선정 확률을 확인하지 않은 임의 가중치가 전국 대표성을 보장하지는 않는다.

표본이 2곳 미만이거나 σ가 0이면 정규분포를 확정하지 않는다. 표준 대상 범위 밖의 값도 같은 식을 사용한다. 분포는 재추정하지 않고 점수의 최댓값·최솟값도 대상 목록에 맞춰 재조정하지 않는다.

각 세부 항목 점수의 중분류 내 동일 비중 평균 → 각 중분류 점수의 대분류 내 동일 비중 평균 → 각 대분류 점수의 동일 비중 평균으로 총점을 계산한다. 누락 항목이 있으면 확인된 항목 점수는 표시하되 중분류·대분류·총점을 확정하지 않는다. 하위 항목 수가 많은 대분류에 더 많은 비중을 주지 않는다.

정규분포 가정에 따른 점수 변환이므로 원자료를 표준화하는 것만으로 원자료의 분포가 정규분포가 되지는 않는다. 편중·비대칭·극단값·순서형 항목의 분포를 확인한 뒤 기준을 확정한다. 전국 실제 백분위나 전국 대표성이 자동으로 보장되는 점수로 표시하지 않는다. 기준이 고정되는 문제와 대표성·모형 적합성 문제는 각각 확인한다.

## 앱 범위와 보관

이번 구현은 표준 대상 선택, 평가 항목 설정, 원자료 직접 입력, 기준 미리보기·확정, 고정 기준 점수, 버전 재적용, JSON 내보내기를 제공한다. 기존 시설 경로 조회는 유지하며 모든 평가 항목의 자동 원자료 수집·시설 후보군 연결은 별도 구현 대상이다. 실제 전국 표준 대상이나 평가 자료를 합성 값으로 채우지 않는다.

좌표·항목 정의·조회 조건이 달라지면 그 조건에 맞는 새 원자료를 요구한다. 이전 조건의 원자료와 확정 기준은 보존한다. 저장 실패 시 미저장 변경을 게시하지 않고, 보관함 형식이나 계수가 틀리면 기존 파일을 보존한다. 같은 공유 폴더를 사용하는 기기에 표준 선택·원자료·평가 항목·기준 버전을 전달하며 큰 기준은 체크섬을 검증하는 조각으로 나눈다. 동일한 버전 ID의 내용 변경은 거부한다.

검증: `bash scripts/test_evaluation_reference.sh`. 정상 CDF 값·꼬리 확률·방향·표본 가중치·안정적 분산 계산, 새 대상/원자료 수정 시 기준 고정, 새 버전과 재적용, 좌표·조건·단위 변경과 누락, 계층별 비중, 저장·손상 보존, 기기간 동일 기준과 큰 기준 조각 복구를 검사한다.

통계 정의 참고: [NIST 정규분포](https://www.itl.nist.gov/div898/handbook/eda/section3/eda3661.htm), [미국 Census 표본 가중치](https://www.census.gov/programs-surveys/sipp/methodology/weighting.html).
