# 입지분석 PC 0.1.2

전국 K-apt 단지정보 파일을 PC에 보관하고, 검증할 표준지 후보를 관리하는 Windows 데스크톱 프로그램입니다. 이번 버전의 범위는 **표준지 목록 관리**입니다.

## Windows에서 실행

1. `LocationAnalysisPC-0.1.2-Windows-x64.zip`을 **모두 압축 해제**합니다.
2. `LocationAnalysisPC` 폴더의 `LocationAnalysisPC.exe`를 실행합니다. `_internal` 폴더도 함께 두어야 합니다.
3. **K-apt 파일 가져오기**를 누르고 내려받은 전국 단지정보 XLSX/XLS/CSV를 선택합니다. Python이나 API 키를 별도로 설치·입력할 필요가 없습니다.

Windows 10/11 64비트용입니다. 이 배포본에는 코드 서명이 없습니다. 최초 실행 시 Windows에서 게시자 확인 안내를 표시할 수 있습니다. macOS 실행파일은 포함하지 않습니다.

## 처음 가져온 다음 할 일

1. 전국 엑셀을 선택하고 단지명·코드·주소 미리보기를 확인합니다. 원본 기준일을 입력하고 전국 전체 파일이면 **전국 전체 목록으로 갱신**을 체크한 뒤 **가져오기 시작**을 누릅니다.
2. **주소 중복 검토**에서 같은 주소의 등록을 비교합니다. 단지를 선택하고 **단지·표준지 검토**를 열어 확인한 중복·멸실만 사유와 함께 제외합니다. 실제 별개 단지는 각각 유지합니다.
3. **표준지 목록 → 표준지 내보내기 → 후보 전체**로 현재 후보 목록을 Excel에 저장할 수 있습니다. 모든 건물·입구를 먼저 입력해야 하는 것은 아닙니다.
4. 공시가격 자료가 준비되면 목록을 가져오거나 직접 등록하고 각 K-apt 단지 검토 창에서 연결합니다. 이 버전은 파일·수동 연결을 지원하며 공시가격 사이트의 도로명·지번 자동 검색은 아직 포함하지 않습니다.
5. 오른쪽 위 **백업**으로 원본·검토·연결 기록 전체를 보관합니다. 후보 목록 Excel은 전체 보관함 백업과 용도가 다릅니다.

밝은 배경과 짙은 글씨를 앱 전체에 적용해 Windows의 어두운 모드에서도 읽을 수 있게 했습니다. 오른쪽 위 **글자 크기**에서 기본·크게·더 크게를 선택하면 다음 실행에도 유지됩니다. 화면의 파란 안내 상자에서 현재 단계에 맞는 다음 작업으로 이동할 수 있습니다.

## 단지정보 가져오기

- [공공데이터포털 K-apt 공동주택 단지 기본정보](https://www.data.go.kr/data/15073271/fileData.do)에서 전체 엑셀을 내려받습니다. 프로그램에는 실제 전국 자료를 미리 넣지 않았습니다.
- 열 이름을 자동 연결하고 처음 최대 8개 행을 보여 줍니다. 미리보기는 단지명·코드·주소를 앞에 표시하고 나머지 원본 열도 유지합니다. 필수 열이 정상 연결되어 있으면 설정은 접어 두며 **열 연결 확인·수정**을 눌러 펼칩니다. K-apt 단지코드·단지명·도로명주소는 필수 열입니다. 여러 시트가 있으면 단지정보 시트를 선택할 수 있습니다.
- 파일 내부의 사용 범위가 `A1`로 잘못 표시된 공식 엑셀도 실제 셀을 읽어 안내문 다음의 제목 행과 전체 단지 목록을 인식합니다. 원본 엑셀을 다시 저장하거나 수정할 필요가 없습니다.
- 가져오기 창은 현재 모니터의 사용 가능한 크기에 맞춥니다. 좁은 창에서는 열 연결 항목을 한 줄씩 배치하며, 미리보기의 많은 열은 표 안에서 가로 스크롤합니다. 긴 열 이름 전체는 마우스를 올려 확인합니다. 아래쪽 가져오기·취소 버튼은 항상 표시합니다.
- **자료 기준일**에는 원본의 실제 기준일을 선택적으로 입력합니다. 파일을 내려받거나 가져온 날짜와 구분합니다. 기준일을 입력하지 않으면 시간 순서 검증이 제한되므로, 정기 갱신 때는 원본에 표시된 기준일을 기록하세요.
- **전국 전체 목록으로 갱신**은 실제 전국 스냅샷일 때만 체크합니다. 지역 자료·추가 자료는 체크하지 않습니다. 전체 목록에서 빠진 코드는 `수록 확인`으로 표시하며 자동 삭제하지 않습니다.
- 원본의 추가 열도 원본 정보에 보존합니다. 정상적으로 가져오기를 마친 뒤 한 번에 반영하며, 오류나 취소 때 기존 자료를 유지합니다.
- XLSX, XLS, UTF-8/CP949 CSV·TSV, 목록 형식 JSON을 지원합니다. 이전 앱의 `records`/`sources` JSON은 원본 목록만 가져옵니다. 이전 앱의 검토·연결·평가 설정까지 자동 이전하는 기능은 아닙니다.

## 표준지 관리 규칙

- **유효한 K-apt 코드 하나당 표준지 하나**입니다. 여러 도로명주소를 가진 한 단지는 표준지 후보 하나로 표시합니다.
- 같은 주소를 쓰는 서로 다른 K-apt 코드는 자동으로 합치지 않습니다. `주소 중복 검토`에서 실제 별개 단지인지, 과거·중복 등록인지 판단합니다. 제외 사유와 채택한 코드를 메모할 수 있습니다.
- 도로명주소 열이 실제 공란인 원본은 `주소 공란`으로 표시하고 후보 목록에서 제외합니다. 상세정보를 아직 받지 않은 이전 JSON과 주소 해석이 불확실한 행은 `주소 확인`으로 남깁니다.
- `공시가격 대조`에서 단지목록 파일을 가져오거나 공시가격 고유 ID로 직접 등록한 뒤, K-apt 단지를 열어 연결합니다. 1:1뿐 아니라 1:N·N:1·N:M 연결을 허용합니다. 자동 크롤링·자동 연결 승인은 이번 버전에 포함하지 않습니다.
- 대표 도로명주소, 확인한 개별 건물·동, 건축물대장 식별자(선택), 건물 소속과 입구 좌표를 기록할 수 있습니다. 확인되지 않은 101동이나 좌표를 자동 생성하지 않습니다.
- 기본적으로 실제 주소·상세주소 자료를 확인해 가장 앞선 건물을 선택하세요. 여러 주소를 가진 단지는 대표 주소를 직접 지정합니다. 실제 동·입구 확인 전에도 후보 목록을 저장할 수 있습니다.
- `유효` 판정, 공시가격 연결, 대표 주소, 건물 명칭·소속, 입구 위경도·확인이 갖춰진 항목을 `확정`으로 표시합니다. 이는 사용자가 입력한 검토 기록의 완료 상태이며 기관의 자동 검증 결과는 아닙니다.

## 갱신·백업·내보내기

- 다시 가져오면 같은 **코드**의 원본만 갱신합니다. 수동 판정·제외·다대다 연결·표준 건물 선택은 보존합니다. 단지 범위나 연결된 공시가격 자료가 바뀌면 `재검토`로 표시합니다.
- `표준지 내보내기`에서 후보 전체 또는 확정 표준지만 Excel/CSV로 저장합니다. 이 내보내기는 화면 필터와 관계없이 해당 범위 전체를 내보냅니다.
- 오른쪽 위 `백업`은 원본·연결·검토·이력을 SQLite 파일 하나로 보관합니다. 다른 PC에서는 `복원`으로 불러옵니다. 복원 직전 현재 보관함도 자동 백업합니다.
- 기본 데이터 위치: `%LOCALAPPDATA%\LocationAnalysisPC\catalog.sqlite3`. `사용 안내 → 데이터 폴더 열기`로 확인합니다. 실행파일을 교체해도 보관함은 유지됩니다.
- 파일 가져오기와 저장은 작업 스레드에서 처리합니다. 표는 150개씩 표시하며, 최소화하거나 다른 창을 사용해도 작업을 계속합니다. PC가 절전·종료되면 작업은 계속되지 않습니다.

## 앞으로 추가할 범위

다음 개발 우선순위는 K-apt 주소로 공시가격 단지를 찾아 연결 후보를 제안하고 사용자가 확인하는 기능입니다. 도로명 검색 후 누락된 경우 지번 검색으로 보완하는 흐름이 필요합니다. 소분류별 평가용 데이터, 건축물대장·입구의 자동 조회, 공간 도형·길찾기, 정규화·점수 계산, 자동 업데이트, 모바일과 PC 연결은 이후 단계입니다. 현재는 데이터 파일 가져오기와 로컬 목록 관리에 API를 사용하지 않습니다.

## 개발·검증

Python 3.12 권장:

```sh
python -m pip install -r requirements.txt
python scripts/fetch_assets.py
python -m location_analysis
```

```sh
python -m unittest discover -s tests -v
python -m location_analysis --self-test build/verification
python -m location_analysis --smoke-test build/verification
```

Windows 실행본 빌드:

```sh
python -m pip install -r requirements-build.txt
python scripts/fetch_assets.py
python scripts/build_windows.py
```

검증은 가상 단지 자료로 진행합니다. 단지 2만 건, 같은 주소의 별개 코드, 한 코드의 여러 주소, 다대다 연결, 제외·재가져오기, 취소 시 롤백, 전체 파일에서의 누락, Excel/CSV 내보내기, 백업·복원을 포함합니다. 배포 워크플로는 생성된 Windows EXE 자체로 저장·복원·화면 검사를 다시 수행합니다.
