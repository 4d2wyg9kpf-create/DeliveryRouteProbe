# 배송경로 0.13.0 · iPhone / iPad

현재 버전은 **0.13.0 / 빌드 24**이며 iOS 18 이상을 지원합니다. 앱 식별자는 `kr.deliverytools.routeprobe`, 기본 표시 이름은 `DeliveryRoute`입니다. 실제 거래처·배송 기록·네이버 로그인·티맵 앱키는 기기에서 보관하거나 입력합니다.

## 네이버 장소와 저장 목록 가져오기

- 검색한 장소의 상세 화면에서 **선택 장소 읽기**를 누르면 이름·주소·좌표를 읽고 거래처 목록에 저장할 수 있습니다. 읽을 때마다 현재 상세 프레임에 요청하고 장소 ID와 주소를 다시 대조합니다.
- **저장 목록 전체 가져오기**를 누르고 가져올 네이버 폴더를 선택하면 목록을 끝까지 로딩한 뒤 각 장소를 거래처 목록에 저장합니다. 표시된 전체 개수와 실제 읽은 개수가 다르면 시작하지 않습니다. 개별 실패와 저장한 개수를 표시하며 중단해도 완료한 항목은 보존합니다. 목록 항목과 상세 주소가 일치하는지도 확인합니다.
- **공유 링크 붙여넣기**에서 네이버의 공유 텍스트나 링크를 입력할 수 있습니다. `naver.me` 단축 링크의 웹 연결을 기다리고 지원되는 장소·폴더 URL을 앱의 네이버 지도 화면으로 연결합니다. 장소 ID를 유지하고 임의의 지도 중심 좌표는 사용하지 않습니다. 장소는 읽은 정보를 확인하여 저장하고, 폴더는 접근 가능한 목록을 가져옵니다. 지원되지 않는 링크나 접근 제한은 실패를 표시합니다. iOS 공유 메뉴에서 이 앱으로 직접 보내는 확장은 포함하지 않습니다.
- 저장 목록 접근에는 네이버의 공개 범위·로그인 상태가 적용됩니다. 네이버 로그인은 본인이 앱의 지도 화면에서 진행합니다.
- iPhone에서는 **지도 보기**로 검색 패널을 접고 **검색·장소**로 다시 펼칠 수 있습니다.

지도 핀의 좌표를 확인할 수 없으면 선택한 주소를 **Apple 주소 변환**으로 조회합니다. 도로·건물번호·지역 또는 전체 지번 주소를 대조하며 다른 주소나 여러 위치가 나온 결과는 좌표로 저장하지 않습니다. 좌표와 조회한 주소를 기기에 캐시하고 요청 간격과 일시 제한을 적용합니다. Apple의 서버 이용 제한이 있을 수 있으며 무제한 조회를 보장하지 않습니다. 별도 API 키는 입력하지 않습니다. 네이버 지역 검색 API나 Naver Cloud Geocoding은 현재 연결하지 않았습니다.

기존에 주소만 저장된 항목은 거래처 목록의 **주소 → 좌표**로 변환할 수 있습니다. 지도 표식이나 주소 변환 좌표는 건물 위치의 후보이므로 실제 차량 정차·하역 위치를 확인해야 합니다. 이 과정에서 티맵 최적화 API를 호출하지 않습니다.

## 이번 배송지·출발지·도착지 선택

**거래처 목록 · 이번 배송 선택**에서 체크한 곳만 이번 배송에 방문합니다. 전체 거래처 목록은 계속 보관하며 한 번에 최대 30곳을 선택합니다.

출발지를 현재 출발지 또는 목록에서 고르고, 최종 도착지는 출발지 복귀 또는 목록의 다른 장소로 설정합니다. 출발지와 도착지는 체크한 배송지와 각각 지정합니다. 위치가 바뀐 구간과 티맵 순서 연결은 무효화하여 이전 경로로 새 장소를 계산하지 않습니다.

**마지막 배송지에서 종료**는 등록한 이동시간을 사용하는 로컬 배송계획에서 지원합니다. 티맵 최적화에는 고정된 최종 도착지가 필요하므로 이 모드에서는 요청 전에 안내하고 티맵 호출을 차단합니다.

하역 위치 좌표의 휴지통으로 배송지 또는 좌표를 지울 수 있고, 거래처 목록에서도 항목을 삭제할 수 있습니다. 네이버에 저장한 원본은 삭제하지 않습니다. 새 앱 아이콘을 포함합니다.

## GitHub Mac 빌드와 설치

main의 앱 소스나 워크플로 변경 또는 Actions의 **Run workflow**로 **Build unsigned iOS IPA**를 실행합니다. 표준 `macos-15` 서버에서 네이버 프레임·공유 링크 검증과 실제 iOS arm64 기기 앱 컴파일을 수행합니다. 검증이 성공한 경우 **DeliveryRouteProbe-unsigned-ipa**에 IPA와 SHA256·버전·기기 대상 보고서를 올립니다. 빌드 로그와 자료는 7일 보관합니다.

서명용 Apple 계정·인증서·티맵 앱키를 GitHub에 등록할 필요는 없습니다. 설치 파일 `DeliveryRouteProbe_0.13.0-24-unsigned.ipa`는 기존처럼 Sideloadly에서 본인 계정으로 서명하여 설치합니다. 기본 앱 이름은 영문 `DeliveryRoute`입니다. 이전 한글 이름이 Apple의 `appIdName`으로 전달되어 거절되던 오류를 막기 위해 메타데이터의 영문 이름 검사를 유지합니다. Sideloadly의 이름 변경 옵션을 사용한다면 영문 이름을 사용하세요.
