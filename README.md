# 배송경로 0.15.1 · iPhone / iPad

**0.15.1 / 빌드 29**, iOS 18 이상. Bundle ID `kr.deliverytools.routeprobe`, 설치 이름 `DeliveryRoute`를 유지합니다.

공공데이터 조회 전의 시각 확인 오류를 수정했습니다. API 루트의 HEAD 응답에 Date가 없어서 조회 전체가 막히던 문제를 해결합니다. 키가 없는 HTTPS 시각 요청은 NAVER 홈페이지와 공공데이터포털을 사용하며 HEAD에서 시각을 읽지 못하면 GET과 다른 호스트를 순서대로 확인합니다. 오래된 캐시·리디렉션·시각 역행은 거부합니다. 업소 응답의 누락되거나 오래된 Date 헤더 때문에 정상 결과를 버리지 않습니다. 기존 인증키·사용량 보관 형식과 한도 차단은 유지합니다. 키·활용승인을 먼저 확인하여 미설정 상태에는 설정 안내를 표시합니다.

## 세 개의 탭

- **네이버검색**: 검색어·주소·공유 링크에서 장소 이름, 주소, WGS84 좌표를 가져옵니다. 저장할 곳을 **티맵 거래처 목록 / 입지 평가대상지 목록** 중에서 선택합니다.
- **티맵최적화**: 전체 거래처 중 이번 배송지만 체크하고 출발지·최종 도착지를 따로 선택합니다. 배송 날짜·출발 시각·배송 작업시간·가능 시간대를 설정한 뒤 API로 최적화합니다. 결과 요약·지도·방문 순서를 같은 탭 상단에 표시합니다.
- **입지분석**: 평가대상지를 따로 보관하고 선택한 장소 주변 업체를 조회합니다. **대전 신규 인허가 · 영업 목록**은 별도 메뉴입니다. 입지 평가 항목과 점수 산정은 추후 구현합니다.

적재 배치·물건 수량·로컬 배송계획 계산·운행 안내 화면은 탭에서 제외했습니다. 기존 거래처·API 키·설정·계획 파일은 보존하며 기존 적재 계산을 새 화면에서 실행하지 않습니다. 티맵 경로 결과를 보기 위해 별도의 배송계획 검증 버튼을 누를 필요가 없습니다.

## 네이버 검색과 공유 링크

업체 검색은 공식 NAVER 지역 검색 API, 주소 변환은 NAVER Cloud Maps Geocoding을 사용합니다. 검색 결과는 최대 5곳이며 이름·주소·좌표를 확인한 뒤 한 곳 또는 결과 전체를 선택한 목록에 저장합니다.

공유한 `naver.me`, NAVER 지도 장소 링크, 저장 폴더 링크를 붙여넣어 가져옵니다. 장소 링크는 장소 확인 화면을 열고, 목록 링크는 전체 항목 수를 대조한 뒤 장소별 상세 정보를 순서대로 읽어 선택한 목록으로 저장합니다. 기존 장소는 주소·이름을 대조해 갱신하고 완료·실패 개수를 표시합니다. 중단해도 완료된 저장은 보존합니다. 지도 중심 좌표를 장소 좌표로 추측하지 않습니다. 정확한 장소 좌표가 없으면 읽은 주소를 공식 API로 변환합니다.

공유 링크 읽기와 개인 저장목록은 NAVER 웹 문서를 사용합니다. 지도 화면을 아이폰에 표시할 필요가 없으며 로그인·접근 확인이 필요할 때만 웹 화면을 열 수 있습니다. 개인·비공개 목록은 로그인 또는 공유 권한이 필요하고, NAVER 문서 구조 변경 시 읽기가 실패할 수 있습니다. 실제 개인 폴더의 읽기는 사용자 계정에서 확인해야 합니다.

두 목록은 독립적으로 보관합니다. 평가대상지에 저장한 곳이 자동으로 배송 거래처에 추가되지 않습니다. 평가대상지와 거래처는 각각 삭제할 수 있습니다. 실제 배송 정차 위치는 건물 좌표와 다를 수 있으므로 거래처 선택 시 확인합니다. 이번 배송은 최대 30곳입니다. 티맵은 고정된 최종 도착지가 필요하며 출발지 복귀 또는 목록의 다른 장소를 선택합니다.

## 공공데이터 활용신청

**기관별 일괄 신청이 아니라 API 서비스별로 신청**합니다. 서비스 안의 여러 조회 기능은 해당 서비스 승인에 포함됩니다. 이 버전은 아래 **6개 서비스**를 사용합니다. 같은 개인·프로젝트 ServiceKey로 승인받은 서비스를 앱의 하나의 공공데이터 인증키로 사용합니다. 별도 승인 확인을 켠 서비스만 요청합니다.

**입지분석 → 설정**에서 공공데이터포털의 일반 인증키(Decoding 권장)를 입력하고 각 서비스의 활용승인을 확인합니다. 집단급식소식품판매업은 다른 서비스이며 이번 요청의 집단급식소와 혼동하지 않습니다. 현재 포털은 6개 서비스의 개발계정 기본 트래픽 10,000회·무료·자동승인을 안내합니다. 승인된 실제 일일 한도를 입력할 수 있습니다.

주변 업체 조회는 WGS84 중심점과 반경을 사용하며 **최대 2,000m**입니다. 100·300·500·1,000·2,000m 중 선택하고 여러 페이지를 조회한 뒤 좌표로 실제 직선거리를 확인합니다. 음식점업만 표시하거나 이름·업종·주소로 결과를 좁힐 수 있습니다. 소상공인시장진흥공단의 영업 중인 상가 자료 기준이며 실제 휴·폐업 반영에는 시차가 있습니다. 자료 기준년월과 조회 시각을 표시합니다.

대전 신규 인허가는 대전광역시와 5개 구를 조회하고 업종 5개를 선택할 수 있습니다. **인허가일자**의 시작일 이상·종료일 다음 날 미만과 **영업상태 01**로 조회하고 주소·상세 영업 상태를 다시 확인합니다. 도로명 주소가 없어도 지번 주소를 표시합니다. 자료 수정일을 신규 등록일로 간주하지 않습니다. 현재 영업/정상인 업소를 인허가일자별로 묶고 이름·업종·주소·전화·자료 갱신시점을 표시합니다. 인허가일자는 실제 개업일·사업자등록일과 다를 수 있습니다. 행안부 API 설명상 매일 갱신되는 2일 전 기준 자료이며 지자체 신고·반영에는 추가 시차가 있을 수 있습니다.

인허가 원본 좌표 **EPSG:5174**를 위도·경도로 사용하지 않습니다. 주변 업체에는 상가정보의 WGS84 좌표를 사용하고 인허가 영업 목록은 공식 주소를 표시합니다.

한 조회가 여러 페이지·지역을 요청할 수 있으며 각 요청을 보내기 전에 사용량을 저장합니다. 실패·중단도 기록하고 한도가 소진되면 재개 시각까지 차단합니다. 서버가 제한하면 앱 기록의 잔여량과 무관하게 차단합니다. 서버 시각을 확인하고 한국시간 일 경계 뒤 5분을 더 기다립니다. 여러 페이지·업종·지역 중 일부가 실패하면 전체 결과로 표시하지 않고 **일부 조회**와 누락 이유를 표시합니다. 자동 재시도는 하지 않습니다. 다른 기기 사용량 자동 연동은 아직 구현하지 않았습니다.

## API 키 유지

티맵 appKey, NAVER 검색/Maps Client ID·Secret, 공공데이터 ServiceKey와 사용량은 기기 Keychain 및 보호된 Application Support 파일에 보관합니다. 앱을 삭제하지 않고 같은 앱으로 업데이트하면 유지합니다. Keychain 접근 그룹 변경 시에도 보호 파일에서 복원하며 저장 순번·체크섬을 대조합니다. 빈 키 입력은 기존 키를 지우지 않습니다. 보관함 손상·저장 실패 시 요청을 차단합니다. 키는 Documents·로그·공개 소스·검증 보고서에 포함하지 않습니다.

네이버 신규 검색 키는 Application Services → **NAVER API HUB → NAVER 검색 → 지역**, 주소 변환 키는 **Maps → Geocoding**에서 따로 발급합니다. CLOVA만 보이는 AI·NAVER API 등록 화면을 사용하지 않습니다. HUB 현재 무료 제공, Maps 무료 대표 계정을 설정에서 확인해야 호출합니다. 기존 Developers 검색 키는 해당 발급처를 선택합니다. NAVER 검색·Maps·티맵의 기존 무료 사용량 기록과 한도 차단을 유지합니다.

공식 안내: [NAVER 검색 이관](https://developers.naver.com/notice/article/32530), [HUB 등록](https://guide.ncloud-docs.com/docs/apihub-application), [지역 검색](https://api.ncloud-docs.com/docs/naver-api-hub-search-local), [Maps Geocoding](https://api.ncloud-docs.com/docs/application-maps-geocoding), [티맵 앱키](https://openapi.sk.com/).

## 빌드와 설치

GitHub Actions **Build unsigned iOS IPA**는 표준 macos-15 서버에서 실제 WKWebView 교차 출처 읽기·공유 링크, NAVER API, 키 유지, 공공데이터 요청 차단 검사를 통과한 뒤 iPhone·iPad용 arm64 기기 앱을 컴파일합니다. 앱 아이콘과 영문 앱 메타데이터를 유지합니다.

`DeliveryRouteProbe_0.15.1-29-unsigned.ipa`는 기존처럼 Sideloadly에서 본인 계정으로 서명하여 설치합니다. Apple 계정·API 키·인증서는 공개 저장소에 입력하지 않습니다.

실제 API 키가 제공되지 않아 인증된 공공데이터·NAVER·티맵 실조회와 실제 iPhone/iPad 설치·업데이트 실행은 별도 확인이 필요합니다. 합성 응답과 모의 네트워크 검사는 무료 호출량을 사용하지 않습니다. 별도로 앱과 같은 URLSession을 사용하는 실제 HTTPS 시각 확인 검사를 실행하며, 이 검사는 API 인증키를 사용하거나 업소 조회를 하지 않습니다.

앱 소스·Xcode 프로젝트·앱 아이콘·빌드 설정·합성 검사만 공개합니다. 개인 거래처·평가대상지·로그인·발급된 API 키와 기기 진단 자료는 포함하지 않습니다.
